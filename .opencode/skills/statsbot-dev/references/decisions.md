# Журнал решений (чтобы не переобсуждать заново)

Продуктовые и технические решения, принятые владельцем. Менять — только если владелец
явно попросил; иначе не «улучшать» самовольно.

## Доступ и права

- Супер-админ один: Telegram id `115965184`. Настройки, админы, чаты, подписки,
  реклама — только он.
- «Жалобы» и «Заблокированные» в меню видят супер-админ и админы канала поездок.
- **Просмотр жалобы открыт всем**, включая открытие ссылки в браузере без Telegram
  (режим чтения). Действия — только автор и админ, проверка на сервере.
- **Хеши/токены в ссылках на жалобы отменены**: номера последовательные, перебор
  признан некритичным (сначала сделали, потом владелец передумал).

## Команда `.статус`

- Доступна **всем** (не только админам).
- Владелец чата и админы **не раскрываются** — показываются как «Участник» (конфиденциально).
- Показываются: ограничение/бан со сроком, «не в чате», «участник».

## Жалобы, баны, чёрный список

- Жалоба: необязательный «на кого» (поиск с аватаром), закрытие с причиной (автору в ЛК),
  переоткрытие автором, комментарии с файлами.
- Бан из жалобы: бан в канале поездок + запись в `banned_user` + сообщение в канал
  со ссылкой на жалобу; автору жалобы — уведомление.
- Забаненный, который пишет боту, получает предупреждение (не чаще раза в час),
  со ссылкой на жалобу, **если она есть**.
- **Экспорта банов из Telegram нет** — Bot API не отдаёт список забаненных.
  Чёрный список залит миграцией `V16` с плейсхолдерами: `banned_by='чёрный список'`,
  `feedback_id=null` (в UI — прочерк).
- Смена «на кого жалоба» после бана запрещена (иначе расходится с `banned_user`).

## Реклама

- Отдельной таблицы предложений нет — используется `ads` со статусами
  `PENDING/APPROVED/ACTIVE/REJECTED`.
- Цена: `100 ⭐` в день (`AdStatus.STARS_PER_DAY`), до 3 вложений, только чаты с
  `enable_ads`.
- Оплата — Telegram Stars (`XTR`), `provider_token` пустой; из-за строгой валидации
  библиотеки используется `StarsInvoiceLink` с переопределённым `validate()`.
- Показ по расписанию (будни/выходные), сверка оплат раз в 10 минут.

## Сообщения и история

- `log` — только последняя версия; `log_edit` — предыдущие (кнопка «История изменений»).
- **Удаление**: Bot API не присылает событий удаления. Пометка «удалено» ставится только
  когда бот удалил сам (фильтр слов). Ручные удаления не отслеживаются — это ограничение
  платформы, не баг.
- Правки старых сообщений (без `message_id`) ищутся по `(chat_id, user_id, date_time)`.

## Квесты

- Пункт «Квесты» в меню видят все: это пользовательская функция; управление —
  только супер-админ.
- «Радиус появления» = радиус, внутри которого чекпоинт открывается и принимается
  ответ. Маркер и окружность видны сразу (иначе квест не найти).
- Чекпоинты добавляются по одному в редакторе, а не списком в multipart-форме.
- Карта — Яндекс.Карты 2.1, ключ в конфиге. Без ключа страницы работают, координаты
  вводятся вручную.
- Координаты присылает браузер, сервер проверяет расстояние. Спуфинг допустим —
  квест развлекательный, не соревновательный с призами.
- Результаты (участники/завершившие) — только супер-админ.
- Удаление чекпоинта каскадно чистит `quest_pass`; квест удаляется каскадом.

## Вёрстка

- Все страницы на переменных `theme.css`, светлая/тёмная тема — обязательна.
- Скрытие — атрибутом `hidden` (`[hidden] { display:none !important }`).
- Никаких отдельных мобильных версий: одна адаптивная вёрстка.

## Инфраструктура

- Секреты — только `config/` (в `.gitignore`) или env; в репозитории — `*.example`.
- Деплой: push в `main` → GitHub Actions → jar → `systemctl restart tgbot`.
- Схема БД — только Flyway; `ddl-auto` не используется.
